# bcljagain_awal

Project latihan web menggunakan PHP dan XAMPP.

Aplikasi ini masih **versi awal**,  
belum ada perubahan tampilan dan fungsi secara signifikan.  
Dibuat untuk belajar:
- PHP dasar
- XAMPP
- Git & GitHub

---

## Cara Menjalankan Aplikasi

1. Install XAMPP
2. Jalankan Apache
3. Letakkan folder project di:
   C:\xampp\htdocs\bcljagain_awal
4. Buka browser
5. Akses:
   http://localhost/bcljagain_awal
